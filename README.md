# CodeAlpha_My_MusicPlayer
A modern music player built with HTML, CSS, and JavaScript featuring play/pause, next/previous, progress bar, volume control, and dynamic song loading.
🚀 Features
▶️ Play / Pause songs
⏭️ Next & Previous controls
🎚️ Interactive progress bar
⏱️ Live song duration & current time
🔊 Volume control
🔇 Mute / Unmute functionality
🎵 Automatic song title handling
📱 Responsive UI
🎨 Custom styled range sliders
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
📂 Project Structure
Music-Player/
│── index.html
│── style.css
│── script.js
│
└── songs/
    ├── song1.mp3
    ├── song2.mp3
    ├── song3.mp3
▶️ How to Run
Download or clone the repository
Open the project folder
Run index.html in your browser
